# Шрифты сайта

**Onest** — заголовки, **Manrope** — текст, **Caveat** — только название в логотипе (одна кириллица). Оба вариативные, один файл на подмножество
покрывает начертания 400–700.

- Источник файлов: Google Fonts (`fonts.gstatic.com`), файлы отдаются с нашего домена —
  обращений к чужим доменам за шрифтами нет.
- Лицензия: SIL Open Font License 1.1, текст в `OFL.txt`.
- Подмножества: кириллица и латиница.
